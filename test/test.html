🕷️ Spider Web Scraper - Test Page

This page contains various test cases for the Spider web scraper.

Section 1: Valid Image Extensions

These images should all be extracted and downloaded:

JPEG Image (Absolute URL)

URL: https://via.placeholder.com/150?text=JPEG.jpg

PNG Image (Absolute URL)

URL: https://via.placeholder.com/150?text=PNG.png

GIF Image (Absolute URL)

URL: https://via.placeholder.com/150?text=GIF.gif

BMP Image (Absolute URL)

URL: https://via.placeholder.com/150?text=BMP.bmp

JPG Image (Uppercase Extension)

URL: https://via.placeholder.com/150?text=JPG.JPG (uppercase)

Section 2: Relative URL Resolution

These images use relative URLs and should be resolved to absolute:

Relative Path (./image.jpg)

URL: ./images/relative.jpg (relative)

Absolute Path (/image.jpg)

URL: /images/absolute.jpg (absolute path)

Parent Directory (../image.jpg)

URL: ../images/parent.jpg (parent directory)

Sibling Directory (images/sibling.jpg)

URL: images/sibling.jpg (sibling directory)

Section 3: Query Parameters and Special Cases

URLs with query parameters and special handling:

Image with Query Parameters

URL: ...?size=large&format=png (should be extracted)

Image with Fragment (Anchor)

URL: ...#section (fragment should be removed by crawler)

Duplicate Image (appears twice)

URL: Same image appears twice (should only download once)

Section 4: Invalid Images (Should be Filtered Out)

These should NOT be extracted:

Video File (MP4)

URL: ...video.mp4 (invalid extension - should be filtered)

PDF Document

URL: ...document.pdf (invalid extension - should be filtered)

Archive File (ZIP)

URL: ...archive.zip (invalid extension - should be filtered)

HTML File

URL: ...page.html (invalid extension - should be filtered)

Section 5: Missing or Empty Attributes (Should be Skipped)

These images should be skipped with no errors:

Image with No src Attribute

No src attribute - should be skipped gracefully

Image with Empty src

src="" - should be skipped gracefully

Responsive Image with srcset

srcset with multiple sizes (first one should be extracted)

Section 6: Links for Recursive Crawling

When using -r flag, spider should follow these links:

Same Domain Links (Should be Followed)

  • Absolute path link
  • Relative path link
  • Gallery page
  • Images directory

These links should be followed during recursive crawling

External Domain Links (Should be Filtered Out)

  • External site (google.com)
  • External site (github.com)
  • External site (example.org)

External links should NOT be followed to stay on-domain

Links with Fragments/Anchors (Should be Cleaned)

  • Link with section anchor
  • Link with top anchor
  • Gallery with anchor

Anchors should be removed from URLs before crawling

Duplicate Links (Should be Detected)

  • Page link (first)
  • Page link (with query param)
  • Page link (duplicate)

Duplicate links should only be visited once

Section 7: Domain Variation Links

Testing same-domain detection with www prefix:

WWW Prefix Variations (Same Domain)

  • With www prefix
  • Without www prefix
  • HTTP version
  • HTTPS version

All should be considered same domain
